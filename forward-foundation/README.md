# Forward Foundation website

Public site for **Forward Foundation Inc.**, a California Nonprofit Public Benefit Corporation supporting underserved communities through education, direct assistance, and access to resources.

## Local preview

```bash
cd forward-foundation
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Contents

- `index.html` — single-page site
- `css/styles.css` — layout, type, motion
- `js/main.js` — nav, reveal motion, contact form feedback
- `assets/` — local imagery
